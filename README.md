# Heritability-binomial-GLMM
Estimation of heritability and repeatability for oviposition acceptance, recorded as a binomial outcome, using mixed-effects models. The analysis focuses on quantifying genetic and environmental sources of variation in a biological trait.

Data
The dataset is publicly available and distributed under an open license. Original source available via DOI: [doi.org/10.5061/dryad.bnzs7h4dn].

Methodology
Binomial generalized linear mixed models were fitted to account for the experimental design and hierarchical data structure. Model diagnostics and validation were performed, and variance components were estimated to assess repeatability and genetic contributions to the trait.

Outputs
The script generates summary tables and graphical outputs illustrating model fit, variance components, and trait repeatability.

How to run
Run the analysis script from the project root directory. All file paths are relative, and no additional configuration is required beyond installing the listed R packages.
